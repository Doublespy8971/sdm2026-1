# Games

Each team's game lives in its own folder: `games/team-1/` to `games/team-4/`.

- The frontend is a **Vite + TypeScript** app. Start from the reference game in [`server/template/`](../server/template).
- Multiplayer runs on Colyseus. Read [server/AGENTS.md](../server/AGENTS.md) for how a game uses the platform.
- Your work branches go into `feature/team-N` first, and `feature/team-N` goes into `main`. See [Branches](../AGENTS.md#branches).
